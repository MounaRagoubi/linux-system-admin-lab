# SSH Basics

## Objective

Practice basic SSH configuration and remote access commands.

## Commands

```bash```

ssh user@server_ip

ssh-keygen

ssh-copy-id user@server_ip

systemctl status ssh

sudo systemctl restart ssh

## What I learned 
- How to connect to a remote machine using SSH
- How to generate SSH keys
- How to copy a public key to a remote machine
- How to check and restart the SSH service
