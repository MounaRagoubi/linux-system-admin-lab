# File Permissions

## Objective

Practice basic Linux file permissions and ownership management.

## Commands

```bash```

ls -l

chmod 755 file.sh

chmod 644 file.txt

chown user:group file.txt

## What I learned 
- How to view file permissions
- How to modify permissions with ```chmod```
- How to change file ownership with ````chown````
- The difference between read, write, and execute permissions
